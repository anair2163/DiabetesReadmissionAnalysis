# 30-Day Readmission Risk Analysis in US Diabetes Hospital Encounters

This project analyzes the Diabetes 130-US Hospitals dataset from the UCI Machine Learning Repository to identify patterns associated with hospital readmission within 30 days.

## Data
Place these files in `data/raw/`:
- diabetic_data.csv
- IDS_mapping.csv

Raw data is not committed to GitHub.

## How to run
pip install -r requirements.txt
jupyter lab

Open:
- notebooks/readmission_analysis.ipynb
